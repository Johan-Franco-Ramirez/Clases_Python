# Fundamentos de Python - Control y Funciones

Este repositorio contiene los ejercicios prácticos desarrollados en Python sobre **estructuras condicionales, estructuras iterativas y funciones**. El proyecto busca aplicar estos conceptos mediante scripts organizados por temática, probados y documentados, los ejemplos no se han agregado en esta actividad.

---

## Requisitos

* Python 3.x instalado.
* Visual Studio Code, PyCharm o editor similar.
* Git y cuenta de GitHub o GitLab para el versionamiento.

---

## Estructura del Proyecto

Los ejercicios se encuentran organizados en la carpeta `src/`, separando cada conjunto de ejercicios según el tema trabajado.

```text
fundamentos_python_control_fun/
│
├── src/
│   ├── condicionales/
│   │   └── reto2.py
│   │
│   ├── funciones/
│   │   └── reto1.py
│   │
│   └── iterativas/
│       └── reto3.py
│
└── README.md
```

Cada carpeta contiene los **ejemplos y ejercicios correspondientes al tema estudiado**, permitiendo mantener el código organizado y facilitar su ejecución y revisión.

## Ejercicios Desarrollados

### 1. Funciones – `src/funciones/reto1.py`

Ejercicio orientado al manejo de funciones y ciclos para registrar el tiempo dedicado a diferentes proyectos y generar un reporte con los resultados.

**Conceptos aplicados:**

* Funciones.
* Listas.
* Ciclos `while`.
* Cálculos de promedios y porcentajes.
* Entrada y salida de datos.

**Ejecución:**

```bash
python src/funciones/reto1.py
```

### 2. Condicionales – `src/condicionales/reto2.py`

Ejercicio de control de inventario que clasifica productos según su cantidad disponible y genera alertas de estado.

**Conceptos aplicados:**

* Condicionales `if`, `elif` y `else`.
* Condicionales anidados.
* Listas.
* Ciclo `for`.
* Función `len()`.

**Ejecución:**

```bash
python src/condicionales/reto2.py
```

### 3. Iterativas – `src/iterativas/reto3.py`

Ejercicio que analiza la frecuencia de palabras dentro de una frase. El programa procesa el texto, cuenta las repeticiones mediante un diccionario y determina la palabra más frecuente.

**Conceptos aplicados:**

* Ciclos `for`.
* Diccionarios.
* Cadenas de texto.
* `lower()`, `replace()` y `split()`.
* Búsqueda de valores máximos.

**Ejecución:**

```bash
python src/iterativas/reto3.py
```
