# Introduccion de Python

Repositorio de prácticas y laboratorios correspondientes a las **Secciones 1 a 4 de Fundamentos de Python**. En este proyecto se trabajan conceptos básicos como la función `print()`, literales, cadenas, operadores, variables, conversiones y expresiones matemáticas.

```text

│

│   ├── LAB_FuncionPrint.py
```

## 📚 Contenido

### Sección 1 – Función `print()`

Se practican diferentes formas de utilizar `print()`, sus argumentos y el formato de salida mediante saltos de línea, separadores y terminadores.

* `LAB_FormatoSalida.py`
* `LAB_FuncionPrint.py`
* `LAB_PrintArgumentos.py`

### Sección 2 – Literales y cadenas

Se trabajan cadenas de texto, comillas, caracteres de escape y saltos de línea.

* `LAB_LiteralesCadenas.py`

### Sección 3 – Operadores

Se practican operaciones matemáticas y el orden de prioridad de los operadores.

* `LAB_EjerciciosOperadores.py`

Se utilizan operadores como:

```text
+   -   *   /   //   %   **
```

### Sección 4 – Variables

Se aplican variables, asignaciones, operaciones, expresiones y conversiones.

* `LAB_Convertidor.py` – Conversiones de unidades, moneda y temperatura.
* `LAB_Gameplay.py` – Ejercicios de algoritmos relacionados con videojuegos.
* `LAB_Operadores.py` – Uso de operadores y expresiones.
* `LAB_Variables.py` – Creación y manipulación de variables.


## ▶️ Cómo ejecutar los programas

Se necesita tener **Python 3** instalado.

Desde la terminal se puede ejecutar cualquier laboratorio con:


```bash
python seccion4/LAB_Gameplay.py
```

Algunos programas solicitan datos mediante `input()`, por lo que será necesario introducir los valores indicados por el programa.
